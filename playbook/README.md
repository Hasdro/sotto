# Playbook

What the AI answers from. Written by you and your best sales agent. Each company in
Sotto will later have its own playbook in the database; these files are the seed and
the test data.

| File | Contents |
|---|---|
| `faq.md` | Top 20 customer questions with the best answer |
| `objections.md` | Top 10 objections with how your best agent handles each |
| `products.md` | Products, packages, prices, what is included |
| `never-promise.md` | Things an agent must never promise (discounts, dates, guarantees) |

Entry format (keep it; retrieval depends on it):

```markdown
## Q: Do you include furniture in the villa package?
- Short answer (≤ 25 words, what the agent can say): ...
- Details (for the agent's eyes): ...
- Follow-up question to ask: ...
- Tags: package, furniture
```
