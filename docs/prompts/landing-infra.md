# Child session: phase9/landing-infra — T-066 and T-067 preparation (AGN Sales Shield 0.8.0 groundwork)

Read `docs/prompts/common.md` first and follow it. Use the `impeccable` skill in Persuade mode, building on the brand-ui tokens. Use the placeholder logo until the owner chooses one.

## Goal
- **Static landing page in a new `apps/landing/`.** Plain HTML and CSS with a tiny script and no framework, unless the repo already has one that fits.
  - Sections: a hero, what the product does, 3–4 feature sections, and screenshot slots for the 0.3.0 screenshots.
  - macOS and Windows download buttons. Detect macOS, with arm64 and x64 choices.
  - System requirements, and first-open steps for the unsigned builds (macOS right-click → Open; Windows SmartScreen → More info → Run anyway).
  - A clearly marked placeholder slot for the Zoho Forms embed (never invent a form), with a short privacy note next to it.
  - Privacy and Terms drafts marked "DRAFT, owner review", and an "AGN IT Services" footer.
  - No pricing, no testimonials, and no invented logos or metrics.
  - Light, dark and RTL, readable at 390 px.
- **Download wiring.** A `downloads.json` manifest (version, file names, sizes, sha256) generated by a script from `apps/desktop/release/`. The buttons read it, so a new version needs no HTML edit.
- **Infrastructure in the repo only.**
  - A Caddy site block for `salesshield.agncompu.com` that serves `apps/landing` and `/downloads/` files with no directory listing.
  - A `deploy/publish-landing.sh` script, plus a cleanup list naming the stale installers, the APK and the extension zip to remove from the old `/downloads/`.
  - A DNS and Cloudflare note: an A record pointing to 104.168.48.116, DNS-only or proxied with the right TLS mode.
  - **Do not run anything against us3 and do not change DNS.** The master runs the scripts after the owner approves.
- **GitHub Releases script.** `scripts/release.sh vX.Y.Z` uses `gh release create` on the private repo with the installers attached and notes taken from the tracker. Write it and dry-run it only. Do not publish.
