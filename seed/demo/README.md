# Demo company (fictional)

**Palm Grove Realty (demo)** is an invented off-plan property brokerage in Dubai. It exists only for the local demo, the synthetic replay calls and tests (D-013). None of these facts describe a real company, and none belong in the owner's `playbook/`.

- `company.yaml`: settings the pipeline reads (name, tone, call goal, holding lines, switches).
- `playbook/`: entries in the `playbook/README.md` format.
- `calls/`: synthetic scripted calls used by `pnpm replay --synthetic` and the demo scenarios.
